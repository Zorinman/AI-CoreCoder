# 06 — 固定工具快照并保护模型上下文

**What to build**：让运行中的 Agent 始终使用一致的 MCP 工具集合，并在 Server 能力变化或工具 Schema 占用过高时向用户提供明确反馈。

**Blocked by**：02 — 打通单个 stdio MCP Server 的完整调用链

**Status**：ready-for-agent

- [ ] MCP 工具仅在启动阶段发现并形成固定工具快照。
- [ ] Agent 运行期间不动态修改工具列表、名称索引、Schema 或系统提示。
- [ ] 收到工具列表变化通知后，把重启提示加入队列而不是立即异步打印。
- [ ] REPL 在下一次显示输入提示符前输出工具快照已过期的警告。
- [ ] 多次相同变化通知不会产生无法控制的重复提示。
- [ ] 启动时估算系统提示和全部工具 Schema 的上下文占用。
- [ ] 估算值超过模型上下文上限时启动失败，超过上限的 25% 时显示警告。
- [ ] 上下文保护同时覆盖内置工具和 MCP 工具，避免只计算消息内容。
- [ ] 工具快照和上下文保护通过 Agent 与 CLI 的可观察行为验证，不依赖私有注册表结构。
