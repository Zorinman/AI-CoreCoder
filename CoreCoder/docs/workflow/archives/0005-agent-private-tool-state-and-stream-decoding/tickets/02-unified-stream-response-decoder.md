# 02 - 统一流式响应解码

**What to build**: 所有 LLM 后端共享同一个流式响应解码行为，用户无论选择哪个后端，都获得相同的文本回调、用量、工具调用组装和容错结果。

**Blocked by**: None - can start immediately.

**Status**: completed

- [x] 各后端只保留请求、获得流和重试的差异；响应解码规则只定义一次。
- [x] 文本、文本回调、用量、按索引分片的工具调用和响应结构在两个后端保持一致。
- [x] 空响应块、缺失可选字段和无效工具参数 JSON 保持当前容错行为。
- [x] 测试通过公开 `chat()` 行为覆盖两个后端的等价流式结果。
