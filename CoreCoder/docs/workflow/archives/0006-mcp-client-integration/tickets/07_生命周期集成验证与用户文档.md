# 07 — 完成生命周期、集成验证与用户文档

**What to build**：把全部 MCP 行为组合成可重复验证的用户流程，并提供足以配置、诊断、禁用和理解费用边界的使用说明。

**Blocked by**：03 — 提供持久用户配置与 CLI 控制；04 — 支持多 Server 聚合与可靠注册；05 — 完善 MCP 工具执行安全与结果处理；06 — 固定工具快照并保护模型上下文

**Status**：completed

- [ ] 本地最小 stdio Server 集成场景覆盖进程启动、初始化、工具发现、工具调用和正常关闭。
- [ ] 集成场景覆盖工具列表变化通知和下一提示符前的重启提醒。
- [ ] 集成场景覆盖 Ctrl+C 或异常退出后的统一清理。
- [ ] MCP 生命周期最多等待 5 秒完成优雅关闭，随后终止仍然存活的 stdio 子进程。
- [ ] 集成场景验证没有遗留 Server 进程或后台线程。
- [ ] CLI 验收覆盖用户级自动连接、临时覆盖、临时禁用、部分失败、全部失败和恢复会话。
- [ ] 用户文档说明配置结构、默认位置、CLI 优先级、环境变量引用、工具命名和启动摘要。
- [ ] 用户文档明确说明不支持的 MCP 能力、工具快照刷新方式、无自动重试及外部费用不受 LLM 硬预算保护。
- [ ] 自动化测试不依赖互联网或真实第三方 MCP Server。
- [ ] 完整测试套件和代码质量检查通过后，本 Ticket 才能标记完成。
